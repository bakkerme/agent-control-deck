# Feedback carried into the desktop transition

- Chat identity must remain visible independently of the latest activity. Two agents using the same tool should still be easy to distinguish.
- Running, idle, attention-needed, and ended states need distinct labels and visual treatment.
- Prompt previews may contain provider markup such as `<user_query>` tags; normalize previews in the future provider adapters.
- Distinguish completed turns from completed work. Do not infer completion from inactivity.
- Validate Windows Cursor and Claude Code in WSL at work, as well as macOS support.
